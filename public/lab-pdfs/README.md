# Laboratory certificates (PDF)

Third-party lab analysis certificates for the catalogue.

The mock commerce data (`lib/commerce/mock-data.ts`) references certificates
here by path via each product's `labResultUrl`, e.g.
`/lab-pdfs/amnesia-haze-interior.pdf`. Drop the real signed PDFs here using the
same file names.

The Análisis / Laboratorio page (FEAT-004) links to these files and shows a
placeholder for any certificate not yet uploaded.
