# Brand assets

This folder holds the visual identity assets for **The Best Dreams**.

## Logo

The real brand mark is a **crowned golden eagle wordmark reading "THE BEST DREAMS"**.

- Drop the final artwork here as **`logo.png`** (transparent background, ideally
  ≥ 1024px wide, gold on transparent to sit on the dark background).
- Application code references **`/brand/logo.png`** and falls back to
  **`/brand/logo.svg`** while the PNG is not present.

### `logo.svg` (placeholder)

`logo.svg` in this folder is an **original, lightweight placeholder** only. It is an
abstract gold geometric emblem (crown-suggesting chevrons above wing-suggesting
arcs plus the wordmark). It intentionally does **not** trace or reproduce the real
crowned golden eagle artwork. Replace it / add `logo.png` before shipping.
